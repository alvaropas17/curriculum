Ejemplos ilustrativos. Las respuestas salen de tu propio historial.

Deja de explicárselo todo otra vez.

Sin esto

  • Repites el contexto en cada sesión.
  • Abres ficheros enormes para encontrar una frase.
  • Rehaces un arreglo que ya funcionó.

Con esto

  • Preguntas al agente que ya usas.
  • Recibes el mensaje exacto, con sesión y fecha.
  • Compruebas la fuente antes de fiarte.

Referencias exactas, no suposiciones.

Solo lectura.

Nunca escribe, indexa ni migra tus historiales.

Tú eliges qué lee.

Nunca cambia de fuente en silencio. Leer otro agente requiere que lo pidas.

Un vacío no es una prueba.

Declara sus huecos. Que algo no aparezca no significa que no pasara.

Tu agente se lo instala solo.

  1. Descarga el repositorio. Abrir GitHub
  2. Abre tu agente con acceso a esa carpeta y pégale este prompt.
  3. Abre una sesión nueva y pregúntale por algo que ya hicisteis.

Requisitos: Windows 10/11 y Python 3.10 o superior.

Prefiero la guía paso a paso

prompt de instalación 
Configura Agent History Search en este equipo.
Repositorio: https://github.com/alvaropas17/agent-history-search
Carpeta del paquete: [RUTA ABSOLUTA]
Agente que usaré: [codex / claude / opencode / pi / omp / pocket]
Historiales que autorizo a leer: [FUENTES Y RUTAS]

Lee el README y la documentación de instalación de la versión descargada.
Comprueba Python 3.10+, sqlite3, la ayuda del CLI y las pruebas offline.
Para Codex o Claude Code, configura el MCP incluido history_mcp.py con un
host fijo y solo los historiales autorizados. Para el resto, configura el
helper history_search.py y su skill o instrucciones locales.
Antes de editar configuración, muestra los cambios propuestos y haz una
copia de seguridad. No sustituyas archivos completos ni toques otros MCP.
Si faltan rutas o autorizaciones, pregúntame. No cambies de fuente tras
un error o un resultado vacío. No modifiques historiales ni borres WAL.
Verifica la conexión real con una lectura mínima autorizada y dime cómo
comprobarla en una sesión nueva. Si falta alguna prueba, indícalo.

Antes de instalarlo.

¿Mis conversaciones salen de mi ordenador?

La herramienta no usa la red. Lo que encuentra se lo entrega a tu agente, así que llega a su modelo como cualquier otro texto que le enseñes.

¿Cuánto cuesta?

Nada. Es de código abierto con licencia MIT, sin cuentas ni claves de API.

¿Funciona en Mac o Linux?

Todavía no lo sé. Está probado en Windows y no depende de paquetes externos, pero no lo he validado en otros sistemas.

¿Cómo se conecta a mi agente?

Codex y Claude Code pueden usar el servidor MCP incluido. OpenCode, Pi, omp y Pi Pocket usan un script de Python con su skill.

¿Un agente puede leer el historial de otro?

Solo si lo autorizas y se lo pides. Nunca cambia de fuente por su cuenta, ni siquiera tras un error o un resultado vacío.

Ya hiciste el trabajo. Pídele a tu agente que lo encuentre.
