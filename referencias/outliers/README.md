## Patrones transversales

- **Lo artesanal y anti-IA atrae** (ambos de @jordans.archivess): papel, textura, lo-fi, objetos reales.
- **Los comentarios son bajos de forma natural** (2–4 por cada 1.000 likes). Solo se disparan con una CTA de palabra clave ("comment 'plugin'"): ×30–50.
- **El significado multiplica**: el de tema emocional y universal ("Change") tuvo 4× las visualizaciones y 5× la proporción de guardados frente al de tema de herramienta. La estética trae likes; la emoción trae guardados y envíos.
- **El contenido de herramienta solo funciona si regala algo**: Premiere sin regalo, 6,6 % de guardados sobre likes; plugin con regalo y CTA, 55 %.
- **Contar el proceso funciona si el método sorprende**: escáner real, 24 % de compartidos sobre likes; función de Premiere, 3 %. Lo físico, raro o "sin IA" se reenvía; una función de una app corriente, no.
- **Los dos de más alcance (Change 4,7 M, Escáner 2,6 M)** comparten fórmula: visual abstracto y oscuro, textura lo-fi real, sin texto en pantalla, una descripción corta que remarca lo artesanal, y muchos compartidos.

## Tres palancas (y para qué usar cada una)

| Objetivo | Palanca | Referencia |
|---|---|---|
| Alcance y crecimiento | Pieza visual + una palabra emocional + serie + "sin IA" | Change |
| Alcance y crecimiento | Pieza visual + método físico sorprendente explicado en la descripción | Escáner |
| Leads y comunidad | Demostración + recurso regalado + "comenta X" | Plugin |
| Evitar | Herramienta o proceso sin regalo ni emoción | Premiere |
