I · Cómo llegué aquí

Ya lo había publicado. No recordaba cómo.

13 de noviembre de 2026, por la noche.

Tenía que volver a publicar la web de marketing. Estaba en Claude Code y me faltaba el comando exacto: el proyecto, la carpeta, la rama.

Sabía que lo había resuelto el día anterior. No sabía en qué chat.

El día anterior…

En una sesión de Pi Pocket, el agente había comprobado el proyecto de Cloudflare Pages y había publicado la web. La respuesta seguía guardada en el historial. Solo había que encontrarla.

Así que le pedí a Claude que la buscara.

II · Cómo lo hace

Tú dices lo que recuerdas. Tu agente hace el resto.

  1. 1. Pídeselo con tus palabras
    «Recupera el comando con el que publicamos la web de marketing. Creo que usamos wrangler. Muéstrame el comando y su fuente.»

    No necesitas escribir los parámetros de la herramienta.

  2. 2. El agente hace una búsqueda concreta
    { "action": "search",
  "query": "wrangler pages deploy",
  "query_variants": ["Deployment complete",
    "alvaropastor-marketing"],
  "limit": 5 }

    Devuelve cinco fragmentos breves, cada uno con su agente, fecha y referencia.

  3. 3. Amplía solo el que encaja
    { "action": "expand",
  "ref": "<referencia elegida de la búsqueda>",
  "context": 500 }

    Lee lo justo alrededor de ese fragmento y te enseña de dónde sale, para que lo compruebes.

III · Qué lee y qué no

Referencias exactas, no suposiciones.

Solo lectura.

Lee los mensajes sin modificarlos ni borrar tus conversaciones.

Tú eliges qué lee.

Solo lee el historial de otro agente si lo autorizas y se lo pides. Nunca cambia de fuente por su cuenta, ni tras un error.

Un vacío no es una prueba.

Declara sus huecos. Que algo no aparezca no significa que no pasara.

¿Mis conversaciones salen de mi ordenador?

La herramienta no usa la red. Lo que encuentra se lo entrega a tu agente, así que llega a su modelo como cualquier otro texto que le enseñes.

¿Funciona en Mac o Linux?

Todavía no lo sé. Está probado en Windows y no depende de paquetes externos, pero no lo he validado en otros sistemas.

IV · Instálalo y pruébalo

Tu agente se lo instala solo.

  1. Descarga el repositorio. Abrir GitHub
  2. Abre tu agente con acceso a esa carpeta y pégale este prompt.
  3. Abre una sesión nueva y haz tu primera prueba. Ver la petición

Requisitos: Windows 10/11 y Python 3.10 o superior.

Prefiero la guía paso a paso

prompt de instalación 
Configura Agent History Search en este equipo.
Repositorio: https://github.com/alvaropas17/agent-history-search
Carpeta del paquete: [RUTA ABSOLUTA]
Agente que usaré: [codex / claude / opencode / pi / omp / pocket]
Historiales que autorizo a leer: [FUENTES Y RUTAS]

Lee el README y la documentación de instalación de la versión descargada.
Comprueba Python 3.10+, sqlite3, la ayuda del CLI y las pruebas offline.
Para Codex o Claude Code, configura el MCP incluido history_mcp.py con un
host fijo y solo los historiales autorizados. Para el resto, configura el
helper history_search.py y su skill o instrucciones locales.
Antes de editar configuración, muestra los cambios propuestos y haz una
copia de seguridad. No sustituyas archivos completos ni toques otros MCP.
Si faltan rutas o autorizaciones, pregúntame. No cambies de fuente tras
un error o un resultado vacío. No modifiques historiales ni borres WAL.
Verifica la conexión real con una lectura mínima autorizada y dime cómo
comprobarla en una sesión nueva. Si falta alguna prueba, indícalo.

Tu primera prueba

Elige algo que ya hayas resuelto.

Abre una sesión nueva y adapta esta petición a una decisión tuya:

Busca en mis conversaciones anteriores la decisión sobre [tema]. Recuerdo [una frase o detalle]. Recupera el mensaje y muéstrame su fuente.

Cuantas más palabras exactas de la conversación incluyas, antes la encuentra. Si recupera lo que recuerdas y puedes localizar el mensaje original, funciona.

Paso a paso.

1 · Comprueba Python y el paquete

En PowerShell, desde la carpeta descargada. Las pruebas no leen tus conversaciones; si fallan, resuelve el error antes de seguir.

py -3 --version
py -3 -c "import sqlite3; print(sqlite3.sqlite_version)"
py -3 -B history_search.py --help
py -3 -B -m unittest discover -s tests
2 · Elige qué historiales autorizas

Rutas habituales en Windows; comprueba las de tu instalación. El agente solo lee otra fuente si se lo pides.

Claude Code  --host claude    $HOME/.claude/projects
Codex        --host codex     $HOME/.codex/sessions
Pi           --host pi        $HOME/.pi/agent/sessions
omp          --host omp       $HOME/.omp/agent/sessions
OpenCode     --host opencode  $HOME/.local/share/opencode/opencode.db
Pi Pocket    --host pocket    $HOME/.pi-pocket/pocket.sqlite
3 · Valida la ruta antes de leer

--plan valida los argumentos, pero no abre el historial ni demuestra que la ruta exista.

py -3 -B history_search.py list --host claude --store "$HOME/.claude/projects" --plan
4 · Conéctalo a mano

Claude Code (supone el paquete en C:/Tools/agent-history-search):

claude mcp add agent-history-search --scope user -- py -3 -B C:/Tools/agent-history-search/history_mcp.py --host claude

Codex: añade este bloque a tu config.toml sin sustituir el archivo. Las rutas deben ser absolutas.

[mcp_servers.agent_history_search]
command = "py"
args = ["-3", "-B", "C:/Tools/agent-history-search/history_mcp.py", "--host", "codex", "--store", "codex=C:/Users/YOUR_USER/.codex/sessions"]
startup_timeout_sec = 30

OpenCode, Pi, omp y Pi Pocket usan history_search.py con su skill. Con OpenCode o Pi Pocket abiertos y un archivo WAL, usa la herramienta de snapshot incluida o cierra la aplicación. No borres el WAL.

5 · Comprueba la conexión

En una sesión nueva, pide que liste tu conversación más reciente con su fuente e ID, sin mostrar el contenido, y comprueba que llama a la herramienta del MCP (o al script). Después busca una palabra que sepas que existe. Si configuraste MCP, una prueba con el script no demuestra que MCP funcione.

Qué puede hacer tu agente

Buscar una frase literal en conversaciones pasadas. Listar y leer sesiones recientes, o una por su ID exacto. Inspeccionar llamadas con --tool-calls: comandos, argumentos y resultados, con fallos marcados solo si el historial lo prueba.

py -3 -B history_search.py search --host claude --store "$HOME\.claude\projects" --query "portfolio-anterior" --limit 1 --context 120
py -3 -B history_search.py expand --host claude --store "$HOME\.claude\projects" --session <id> --entry <id> --context 400
py -3 -B history_search.py search --host claude --store "$HOME\.claude\projects" --tool-calls --state failure --since 2026-10-25 --limit 1
